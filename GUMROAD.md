## Description

**Stock counts shouldn't require a WiFi-dependent scanner gun and a monthly SaaS bill.**

TPT Inventory is an offline barcode counting app: import your SKU list, scan items with your phone or tablet camera, and get a live running count — all on-device, with no internet connection required once it's loaded.

- **Import your SKU list** — paste SKUs or upload a CSV, with optional expected quantities
- **Live camera scanning** — supports QR, Data Matrix, Code 128, Code 39, EAN-13, and UPC-A
- **Tally counting** — each scan adds +1, so you can rescan to count multiples of the same item
- **Unexpected-item detection** — flags anything scanned that isn't in your loaded SKU list
- **Live count dashboard** — total SKUs, total scanned, unexpected count, searchable table
- **100% offline** — once installed, use it in the back room, the warehouse floor, or wherever signal doesn't reach
- **Export count CSV** — reconcile against your existing system afterward
- **No account, no upload, no ongoing subscription** — your SKU list and counts never leave the device

### Who it's for
Small shops, warehouses, and market/pop-up sellers who need a fast, reliable stock count without paying for enterprise inventory software or a recurring subscription.

### How it's delivered
Your purchase is a ZIP download containing:
- **The Windows installer** (`.msi`/`.exe`) — double-click to install, run it like any desktop app. No internet connection needed after install.
- **A self-host bundle** for phone/tablet use — drag one folder onto a free instant-hosting page (steps included in the download) to get it on a phone or tablet for walking the floor.

Nothing about this product depends on any ongoing service from us — once installed (or self-hosted), it's yours to keep working indefinitely.

## FAQ

**What barcode formats does it read?**
QR Code, Data Matrix, Code 128, Code 39, EAN-13, and UPC-A.

**Does it need WiFi on the warehouse floor?**
No — after installing, it works fully offline.

**Can multiple people count at once?**
Yes — install the desktop app or the self-hosted phone/tablet version on each device; each tracks its own local copy. Export each device's CSV and merge/reconcile at the end (a full multi-device live sync is a possible future upgrade, not included in v1).

**What if I scan something not on my SKU list?**
It's added automatically and flagged "Unexpected" so you can review it — useful for catching mis-shelved or unlisted stock.

**Is my count data safe if I close the app?**
Yes — it's stored locally in the browser (IndexedDB), so it persists between sessions on the same device.
